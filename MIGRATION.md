## Firebase only if necessary

Add Firebase only for features that cannot stay static:

- authenticated client access
- saved consultation submissions
- file uploads
- admin-managed dynamic content

If those needs appear, add Firebase in layers rather than rebuilding the whole site around it.

## Content rule

- Do not copy Wix page copy verbatim into the new site.
- Keep the new site structurally similar, but rewrite the text in a fresh voice.
- Use the Wix site as a layout and feature reference, not as source text for direct reuse.
